#T INTRO Rozgrzewka i problem: kolejność ustawiana strzałkami
Rozgrzewka: Do czego służy `layout` w Motion? Dlaczego `AnimatePresence` musi zostać w drzewie? Jak Motion obsługuje ustawienie „ogranicz ruch”?

Problem: w DevDesk kolejność ticketów w kolejce „Na dziś” ustawia się przyciskami „↑” i „↓” — przeniesienie zadania z dziesiątego na pierwsze miejsce to dziewięć kliknięć. Zespół chce też tablicy Kanban: kolumny „Otwarte”, „W toku”, „Zamknięte” i karty przenoszone między nimi. Natywne HTML5 Drag and Drop (`draggable`, `ondragstart`) nie działa na ekranach dotykowych, nie obsługuje klawiatury, a podgląd przeciąganego elementu trudno ostylować. W tej lekcji zbudujesz sortowaną listę i przenoszenie między kolumnami z biblioteką **dnd-kit** — z obsługą myszy, dotyku, klawiatury i czytników ekranu.

#T DEFINITION Elementy dnd-kit
Pakiety: `@dnd-kit/core` (mechanizm przeciągania), `@dnd-kit/sortable` (listy z kolejnością), `@dnd-kit/utilities` (pomocnicze, np. `CSS.Transform`).
- **`DndContext`** — obszar, w którym działa przeciąganie; przyjmuje czujniki, algorytm wykrywania kolizji i zdarzenia `onDragStart`, `onDragOver`, `onDragEnd`, `onDragCancel`.
- **Czujniki (sensors)** — skąd przychodzi gest: `PointerSensor` (mysz, dotyk, rysik) i `KeyboardSensor` (spacja podnosi, strzałki przesuwają, spacja upuszcza, Escape anuluje). `activationConstraint: { distance: 5 }` sprawia, że zwykłe kliknięcie w kartę nie zaczyna przeciągania.
- **`SortableContext`** + **`useSortable({ id })`** — element listy dostaje `setNodeRef`, `attributes`, `listeners`, `transform` i `transition`; biblioteka przesuwa sąsiadów, robiąc miejsce.
- **`useDroppable({ id })`** — obszar, na który można upuścić (np. pusta kolumna).
- **`DragOverlay`** — podgląd przeciąganego elementu renderowany ponad stroną (nie jest przycinany przez `overflow` kolumny).
- **`arrayMove(tablica, z, do)`** — zwraca **nową** tablicę z przeniesionym elementem (niemutowalnie).

Biblioteka nie zmienia Twoich danych — w `onDragEnd` dostajesz `active.id` (co przeciągano) i `over.id` (nad czym upuszczono) i sam aktualizujesz stan.

#T CODE_JSX Sortowana kolejka ticketów (JSX)
Każdy wiersz ma uchwyt (przycisk ⠿) — przeciąganie zaczyna się od uchwytu, więc reszta wiersza zostaje klikalna, a uchwyt jest osiągalny klawiszem Tab.
```
// SortableQueue.jsx
import { DndContext, KeyboardSensor, PointerSensor, closestCenter, useSensor, useSensors } from '@dnd-kit/core';
import { SortableContext, arrayMove, sortableKeyboardCoordinates, useSortable, verticalListSortingStrategy } from '@dnd-kit/sortable';
import { CSS } from '@dnd-kit/utilities';
import { useState } from 'react';

function SortableRow({ ticket }) {
  const { attributes, listeners, setNodeRef, setActivatorNodeRef, transform, transition, isDragging } = useSortable({ id: ticket.id });

  return (
    <li ref={setNodeRef} style={{ transform: CSS.Transform.toString(transform), transition, opacity: isDragging ? 0.5 : 1 }}>
      <button type="button" ref={setActivatorNodeRef} {...attributes} {...listeners} aria-label={`Przenieś: ${ticket.title}`}>
        ⠿
      </button>
      {ticket.title}
    </li>
  );
}

export function SortableQueue({ initial }) {
  const [tickets, setTickets] = useState(initial);
  const sensors = useSensors(
    useSensor(PointerSensor, { activationConstraint: { distance: 5 } }),
    useSensor(KeyboardSensor, { coordinateGetter: sortableKeyboardCoordinates }),
  );

  function handleDragEnd({ active, over }) {
    if (!over || active.id === over.id) return;
    setTickets((list) => {
      const from = list.findIndex((t) => t.id === active.id);
      const to = list.findIndex((t) => t.id === over.id);
      return arrayMove(list, from, to);
    });
  }

  return (
    <DndContext sensors={sensors} collisionDetection={closestCenter} onDragEnd={handleDragEnd}>
      <SortableContext items={tickets.map((t) => t.id)} strategy={verticalListSortingStrategy}>
        <ol className="queue">
          {tickets.map((t) => <SortableRow key={t.id} ticket={t} />)}
        </ol>
      </SortableContext>
    </DndContext>
  );
}
```

#T CODE_TSX Sortowana kolejka ticketów (TSX)
`DragEndEvent` opisuje zdarzenie końca przeciągania; `active.id` i `over.id` mają typ `UniqueIdentifier` (`string | number`) — porównujesz je z ID danych.

import { DndContext, KeyboardSensor, PointerSensor, closestCenter, useSensor, useSensors, type DragEndEvent } from '@dnd-kit/core';

#T NOTE JSX ↔ TSX — identyfikatory i dane zdarzeń
W TSX `active.id` i `over.id` to `UniqueIdentifier`, a `over` może być `null` (upuszczono poza obszarem) — kompilator wymusi sprawdzenie `if (!over)`. W JSX zapomniane sprawdzenie skończy się `TypeError: Cannot read properties of null` przy upuszczeniu karty obok listy. Jeśli w ID mieszasz liczby z tekstami (ticket `5` i kolumna `'OPEN'`), typ `string | number` pozwoli to wyrazić, ale łatwo o pomyłkę `5 !== '5'` — trzymaj jeden rodzaj ID albo nadawaj prefiksy (`ticket-5`, `column-OPEN`).

#T DEFINITION Przenoszenie między kolumnami
Gdy elementy przenosisz między listami (Kanban), potrzebujesz dwóch zdarzeń:
- **`onDragOver`** — gdy karta przejdzie nad **inną kolumnę**, od razu przenosisz ją w stanie do tej kolumny (wtedy `SortableContext` nowej kolumny robi dla niej miejsce na żywo),
- **`onDragEnd`** — ustala ostateczną pozycję w kolumnie (`arrayMove`) i zapisuje zmianę (np. w API).

Pusta kolumna nie ma elementów, nad którymi można upuścić, więc sama kolumna musi być obszarem `useDroppable`. Algorytm kolizji `closestCorners` sprawdza się w układach wielokolumnowych lepiej niż `closestCenter`. Stan najwygodniej trzymać jako obiekt `{ OPEN: [id…], IN_PROGRESS: [id…], CLOSED: [id…] }` — kolejność w kolumnie to kolejność ID.

#T CODE_JSX Dwie kolumny z przenoszeniem kart (JSX)
Uproszczona wersja tablicy: przenoszenie między kolumnami i sortowanie w kolumnie. Pełną tablicę z animacjami i zapisem zbudujesz w lekcji Boss.
```
// MiniBoard.jsx
import { DndContext, DragOverlay, KeyboardSensor, PointerSensor, closestCorners, useDroppable, useSensor, useSensors } from '@dnd-kit/core';
import { SortableContext, arrayMove, sortableKeyboardCoordinates, useSortable } from '@dnd-kit/sortable';
import { CSS } from '@dnd-kit/utilities';
import { useState } from 'react';

function Card({ id, title }) {
  const { attributes, listeners, setNodeRef, transform, transition, isDragging } = useSortable({ id });
  return (
    <li ref={setNodeRef} {...attributes} {...listeners} className="card"
      style={{ transform: CSS.Transform.toString(transform), transition, opacity: isDragging ? 0.4 : 1 }}>
      {title}
    </li>
  );
}

function Column({ id, title, ids, titles }) {
  const { setNodeRef, isOver } = useDroppable({ id });
  return (
    <section className={isOver ? 'column column--over' : 'column'}>
      <h3>{title} ({ids.length})</h3>
      <SortableContext items={ids}>
        <ul ref={setNodeRef} className="column__list">
          {ids.map((cardId) => <Card key={cardId} id={cardId} title={titles[cardId]} />)}
        </ul>
      </SortableContext>
    </section>
  );
}

export function MiniBoard({ titles }) {
  const [columns, setColumns] = useState({ todo: ['t1', 't2', 't3'], done: ['t4'] });
  const [activeId, setActiveId] = useState(null);
  const sensors = useSensors(
    useSensor(PointerSensor, { activationConstraint: { distance: 5 } }),
    useSensor(KeyboardSensor, { coordinateGetter: sortableKeyboardCoordinates }),
  );

  const findColumn = (id) => (id in columns ? id : Object.keys(columns).find((key) => columns[key].includes(id)));

  function handleDragOver({ active, over }) {
    if (!over) return;
    const from = findColumn(active.id);
    const to = findColumn(over.id);
    if (!from || !to || from === to) return;
    setColumns((cols) => ({
      ...cols,
      [from]: cols[from].filter((id) => id !== active.id),
      [to]: [...cols[to], active.id],
    }));
  }

  function handleDragEnd({ active, over }) {
    setActiveId(null);
    if (!over) return;
    const column = findColumn(active.id);
    if (!column || column !== findColumn(over.id)) return;
    setColumns((cols) => {
      const list = cols[column];
      const overIndex = over.id === column ? list.length - 1 : list.indexOf(over.id);
      return { ...cols, [column]: arrayMove(list, list.indexOf(active.id), overIndex) };
    });
  }

  return (
    <DndContext sensors={sensors} collisionDetection={closestCorners}
      onDragStart={({ active }) => setActiveId(active.id)} onDragOver={handleDragOver} onDragEnd={handleDragEnd}
      onDragCancel={() => setActiveId(null)}>
      <div className="board">
        <Column id="todo" title="Do zrobienia" ids={columns.todo} titles={titles} />
        <Column id="done" title="Zrobione" ids={columns.done} titles={titles} />
      </div>
      <DragOverlay>{activeId ? <div className="card card--overlay">{titles[activeId]}</div> : null}</DragOverlay>
    </DndContext>
  );
}
```

#T CODE_TSX Dwie kolumny z przenoszeniem kart (TSX)
```
// MiniBoard.tsx
import {
  DndContext, DragOverlay, KeyboardSensor, PointerSensor, closestCorners, useDroppable, useSensor, useSensors,
  type DragEndEvent, type DragOverEvent, type UniqueIdentifier,
} from '@dnd-kit/core';
import { SortableContext, arrayMove, sortableKeyboardCoordinates, useSortable } from '@dnd-kit/sortable';
import { CSS } from '@dnd-kit/utilities';
import { useState } from 'react';

type ColumnId = 'todo' | 'done';
type Columns = Record<ColumnId, string[]>;
type Titles = Record<string, string>;

function Card({ id, title }: { id: string; title: string }) {
  const { attributes, listeners, setNodeRef, transform, transition, isDragging } = useSortable({ id });
  return (
    <li ref={setNodeRef} {...attributes} {...listeners} className="card"
      style={{ transform: CSS.Transform.toString(transform), transition, opacity: isDragging ? 0.4 : 1 }}>
      {title}
    </li>
  );
}

function Column({ id, title, ids, titles }: { id: ColumnId; title: string; ids: string[]; titles: Titles }) {
  const { setNodeRef, isOver } = useDroppable({ id });
  return (
    <section className={isOver ? 'column column--over' : 'column'}>
      <h3>{title} ({ids.length})</h3>
      <SortableContext items={ids}>
        <ul ref={setNodeRef} className="column__list">
          {ids.map((cardId) => <Card key={cardId} id={cardId} title={titles[cardId]} />)}
        </ul>
      </SortableContext>
    </section>
  );
}

export function MiniBoard({ titles }: { titles: Titles }) {
  const [columns, setColumns] = useState<Columns>({ todo: ['t1', 't2', 't3'], done: ['t4'] });
  const [activeId, setActiveId] = useState<string | null>(null);
  const sensors = useSensors(
    useSensor(PointerSensor, { activationConstraint: { distance: 5 } }),
    useSensor(KeyboardSensor, { coordinateGetter: sortableKeyboardCoordinates }),
  );

  const findColumn = (id: UniqueIdentifier): ColumnId | undefined =>
    id in columns ? (id as ColumnId) : (Object.keys(columns) as ColumnId[]).find((key) => columns[key].includes(String(id)));

  function handleDragOver({ active, over }: DragOverEvent) {
    if (!over) return;
    const from = findColumn(active.id);
    const to = findColumn(over.id);
    if (!from || !to || from === to) return;
    setColumns((cols) => ({
      ...cols,
      [from]: cols[from].filter((id) => id !== active.id),
      [to]: [...cols[to], String(active.id)],
    }));
  }

  function handleDragEnd({ active, over }: DragEndEvent) {
    setActiveId(null);
    if (!over) return;
    const column = findColumn(active.id);
    if (!column || column !== findColumn(over.id)) return;
    setColumns((cols) => {
      const list = cols[column];
      const overIndex = over.id === column ? list.length - 1 : list.indexOf(String(over.id));
      return { ...cols, [column]: arrayMove(list, list.indexOf(String(active.id)), overIndex) };
    });
  }

  return (
    <DndContext sensors={sensors} collisionDetection={closestCorners}
      onDragStart={({ active }) => setActiveId(String(active.id))} onDragOver={handleDragOver} onDragEnd={handleDragEnd}
      onDragCancel={() => setActiveId(null)}>
      <div className="board">
        <Column id="todo" title="Do zrobienia" ids={columns.todo} titles={titles} />
        <Column id="done" title="Zrobione" ids={columns.done} titles={titles} />
      </div>
      <DragOverlay>{activeId ? <div className="card card--overlay">{titles[activeId]}</div> : null}</DragOverlay>
    </DndContext>
  );
}
```

#T DEFINITION Dostępność przeciągania
Przeciąganie myszą to tylko jeden ze sposobów. dnd-kit daje z pudełka:
- **klawiaturę** — fokus na uchwycie, spacja/Enter podnosi, strzałki przesuwają, spacja upuszcza, Escape anuluje (wymaga `KeyboardSensor` i `sortableKeyboardCoordinates`),
- **atrybuty ARIA** na uchwycie (`role="button"`, `aria-roledescription="sortable"`, `aria-describedby` z instrukcją),
- **komunikaty dla czytników ekranu** w regionie `aria-live` przy podniesieniu, przesunięciu i upuszczeniu — domyślnie po angielsku i z technicznymi ID, więc podajesz własne przez `accessibility={{ announcements, screenReaderInstructions }}` w `DndContext`.

Mimo to zostaw **alternatywę bez przeciągania**: menu „Przenieś do…” z listą kolumn albo przyciski „↑ / ↓”. Niektórzy użytkownicy (drżenie rąk, przełączniki, sterowanie głosem) nie wykonają gestu przeciągania niezależnie od jakości implementacji — to wymaganie WCAG 2.2 (kryterium 2.5.7 „Ruchy przeciągania”).

#T CODE_PRACTICAL Polskie komunikaty dla czytników ekranu
```
// dndAnnouncements.ts
import type { Announcements, ScreenReaderInstructions } from '@dnd-kit/core';

export function createAnnouncements(titleOf: (id: string | number) => string): Announcements {
  return {
    onDragStart: ({ active }) => `Podniesiono kartę ${titleOf(active.id)}.`,
    onDragOver: ({ active, over }) =>
      over ? `Karta ${titleOf(active.id)} jest nad: ${titleOf(over.id)}.` : `Karta ${titleOf(active.id)} jest poza listą.`,
    onDragEnd: ({ active, over }) =>
      over ? `Upuszczono kartę ${titleOf(active.id)} na: ${titleOf(over.id)}.` : `Upuszczono kartę ${titleOf(active.id)} poza listą.`,
    onDragCancel: ({ active }) => `Anulowano przenoszenie karty ${titleOf(active.id)}. Wróciła na swoje miejsce.`,
  };
}

export const screenReaderInstructions: ScreenReaderInstructions = {
  draggable: 'Aby podnieść kartę, naciśnij spację lub Enter. Strzałkami zmieniasz położenie, spacją upuszczasz, Escape anuluje.',
};
```

#T PITFALL Przeciąganie, które walczy z przewijaniem i klikaniem
Bez `activationConstraint` każdy `pointerdown` na karcie zaczyna przeciąganie — kliknięcia w linki i przyciski wewnątrz karty przestają działać, a na telefonie nie da się przewinąć listy palcem (gest przewijania staje się przeciąganiem). Rozwiązania: próg odległości (`distance: 5`) dla myszy, opóźnienie dla dotyku (`TouchSensor` z `delay: 250, tolerance: 5` — przytrzymanie palca podnosi kartę), uchwyt jako jedyny aktywator (`setActivatorNodeRef`) i CSS `touch-action: none` **tylko** na uchwycie, nie na całej karcie. Druga pułapka: `useSortable` przypisane do elementu, który ma `overflow: hidden` w kolumnie — przeciągana karta jest przycinana; od tego jest `DragOverlay`.

#T SUMMARY Kryterium akceptacji i podsumowanie
dnd-kit dzieli przeciąganie na `DndContext` (czujniki, kolizje, zdarzenia), `SortableContext` z `useSortable` dla list z kolejnością, `useDroppable` dla obszarów upuszczania i `DragOverlay` dla podglądu. Dane zmieniasz sam: `arrayMove` w `onDragEnd`, przeniesienie między kolumnami w `onDragOver`. Czujniki myszy/dotyku z progiem aktywacji i czujnik klawiatury, własne komunikaty `aria-live` po polsku oraz alternatywa bez przeciągania czynią funkcję dostępną. W TSX `DragEndEvent`, `UniqueIdentifier` i `over: … | null` wymuszają obsługę upuszczenia poza listą.

Kryterium akceptacji: kolejkę „Na dziś” da się przestawić myszą, palcem (bez blokowania przewijania) i klawiaturą; czytnik ekranu ogłasza po polsku podniesienie, przesunięcie i upuszczenie; kliknięcie tytułu nadal otwiera ticket; nowa kolejność zapisuje się w API, a błąd zapisu przywraca poprzednią; w `MiniBoard` karty przenoszą się także do pustej kolumny.
