#T INTRO Trening: pola kontrolowane i formularze
Pole kontrolowane to najprostszy i najczęściej używany mechanizm formularzy w React: **wartość pola pochodzi ze stanu, a każda zmiana przechodzi przez handler**. Biblioteki (React Hook Form, akcje formularzy) są wygodne, ale pod spodem opierają się na tych samych zdarzeniach. Ten trening utrwala ręczną obsługę każdego typu pola, zanim zaczniesz ją automatyzować.

Wzór, który przewija się przez całą lekcję:

`value={form.pole}` + `onChange={(e) => setForm((f) => ({ ...f, pole: e.target.value }))}`

Zadania budują formularz zapisu na warsztaty — od dwóch pól do pełnego formularza z walidacją, polami zależnymi i dynamiczną listą. Każde zadanie rozbudowuje poprzednie; rozwiązania pokazują pełny komponent w danym kroku.

#T STEP_BY_STEP Zadanie 1 — wiele pól, jeden stan i jeden handler
Napisz `SignupForm` z polami „Imię” i „E-mail”.

Wymagania:
1. Jeden stan `form` = `{ name: '', email: '' }`.
2. Jeden handler `handleChange` dla obu pól — rozpoznaje pole po atrybucie `name` inputa: `[e.target.name]: e.target.value`.
3. Każde pole ma `<label htmlFor>` i `id`.
4. Pod formularzem podgląd stanu w `<pre>`.

Sprawdź się: dodanie trzeciego pola („Firma”) wymaga dopisania tylko klucza w stanie i jednego `<input>`.

#T CODE_JSX Rozwiązanie 1 (JSX)
```
// SignupForm.jsx
import { useState } from 'react';

export function SignupForm() {
  const [form, setForm] = useState({ name: '', email: '' });

  function handleChange(e) {
    const { name, value } = e.target;
    setForm((f) => ({ ...f, [name]: value }));
  }

  return (
    <form>
      <label htmlFor="name">Imię</label>
      <input id="name" name="name" value={form.name} onChange={handleChange} />
      <label htmlFor="email">E-mail</label>
      <input id="email" name="email" type="email" value={form.email} onChange={handleChange} />
      <pre>{JSON.stringify(form, null, 2)}</pre>
    </form>
  );
}
```

#T NOTE JSX ↔ TSX — klucz obliczany [name] nie jest sprawdzany
`e.target.name` ma typ `string`, więc `{ ...f, [name]: value }` przejdzie kompilację nawet przy literówce w atrybucie `name="emial"` — w stanie pojawi się nowy klucz, a pole przestanie się zmieniać. Jeśli chcesz, by TS pilnował nazw, zrób handler „fabrykę”: `const field = (key: keyof SignupForm) => (e: ChangeEvent<HTMLInputElement>) => setForm((f) => ({ ...f, [key]: e.target.value }))` i pisz `onChange={field('email')}`. W JSX wersja z `name` jest najkrótsza — ale literówkę wykryjesz dopiero w przeglądarce.

#T STEP_BY_STEP Zadanie 2 — checkbox, radio, select i textarea w jednym handlerze
Rozbuduj formularz o pola:
- „Poziom” — trzy przyciski radio: `beginner`, `intermediate`, `advanced`,
- „Format” — `select` z opcjami `online` i `onsite`,
- „Uwagi” — `textarea`,
- „Akceptuję regulamin” — checkbox (`terms: false`).

Wymagania:
1. Wszystkie pola obsługuje ten sam `handleChange`.
2. Checkbox czyta `checked`, a nie `value`: `type === 'checkbox' ? checked : value`.
3. Radio: każdy ma ten sam `name="level"`, swój `value` i `checked={form.level === 'beginner'}`.

Sprawdź się: zaznaczenie checkboxa daje w podglądzie `"terms": true` (wartość logiczną, nie tekst `"on"`).

#T CODE_JSX Rozwiązanie 2 (JSX)
```
// WorkshopForm.jsx
import { useState } from 'react';

const LEVELS = { beginner: 'Początkujący', intermediate: 'Średni', advanced: 'Zaawansowany' };

export function WorkshopForm() {
  const [form, setForm] = useState({ name: '', level: 'beginner', format: 'online', notes: '', terms: false });

  function handleChange(e) {
    const { name, value, type } = e.target;
    const next = type === 'checkbox' ? e.target.checked : value;
    setForm((f) => ({ ...f, [name]: next }));
  }

  return (
    <form>
      <label>Imię <input name="name" value={form.name} onChange={handleChange} /></label>
      <fieldset>
        <legend>Poziom</legend>
        {Object.entries(LEVELS).map(([value, label]) => (
          <label key={value}>
            <input type="radio" name="level" value={value} checked={form.level === value} onChange={handleChange} />
            {label}
          </label>
        ))}
      </fieldset>
      <label>
        Format
        <select name="format" value={form.format} onChange={handleChange}>
          <option value="online">Online</option>
          <option value="onsite">Stacjonarnie</option>
        </select>
      </label>
      <label>Uwagi <textarea name="notes" value={form.notes} onChange={handleChange} /></label>
      <label>
        <input type="checkbox" name="terms" checked={form.terms} onChange={handleChange} /> Akceptuję regulamin
      </label>
      <pre>{JSON.stringify(form, null, 2)}</pre>

  );
}
```

```
type WorkshopForm = { name: string; level: Level; format: 'online' | 'onsite'; notes: string; terms: boolean };
type FieldElement = HTMLInputElement | HTMLSelectElement | HTMLTextAreaElement;

const LEVELS: Record<Level, string> = { beginner: 'Początkujący', intermediate: 'Średni', advanced: 'Zaawansowany' };

export function WorkshopForm() {
```

#T STEP_BY_STEP Zadanie 3 — liczby w polach: liczba uczestników
Dodaj pole „Liczba miejsc” (`type="number"`, od 1 do 5) i wylicz cenę: 120 zł za miejsce.

Wymagania:
1. W stanie trzymaj **tekst** z pola (`seats: '1'`) — tak, by użytkownik mógł wyczyścić pole i wpisać nową liczbę.
2. Liczbę wyliczaj: `const seatsNumber = Number(form.seats)`; pusta wartość lub spoza zakresu → komunikat „Podaj liczbę od 1 do 5”, a cena się nie wyświetla.
3. Cena: `seatsNumber * 120`, sformatowana `toLocaleString('pl-PL', { style: 'currency', currency: 'PLN' })`.
4. Atrybuty `min`, `max`, `step` na polu — ale nie polegaj na nich w logice.

Sprawdź się: wyczyszczenie pola nie wpisuje w nie od razu „0”, a cena znika zamiast pokazywać „0,00 zł”.

#T CODE_JSX Rozwiązanie 3 (JSX)
```
// SeatsField.jsx
import { useState } from 'react';

const PRICE = 120;
const pln = (v) => v.toLocaleString('pl-PL', { style: 'currency', currency: 'PLN' });

export function SeatsField() {
  const [seats, setSeats] = useState('1');
  const seatsNumber = Number(seats);
  const valid = seats !== '' && Number.isInteger(seatsNumber) && seatsNumber >= 1 && seatsNumber <= 5;

  return (
    <div>
      <label htmlFor="seats">Liczba miejsc</label>
      <input
        id="seats"
        type="number"
        min={1}
        max={5}
        step={1}
        value={seats}
        onChange={(e) => setSeats(e.target.value)}
        aria-invalid={!valid}
        aria-describedby="seats-info"
      />
      <p id="seats-info">{valid ? `Do zapłaty: ${pln(seatsNumber * PRICE)}` : 'Podaj liczbę od 1 do 5'}</p>
    </div>
  );
}
```

#T NOTE Dlaczego tekst, a nie liczba w stanie
Gdyby handler robił `setSeats(Number(e.target.value))`, wyczyszczenie pola dałoby `Number('') === 0` i w polu natychmiast pojawiłoby się „0” — nie da się skasować cyfry i wpisać nowej. Do serwera wysyłasz już przekonwertowaną wartość.

#T CODE_BASIC Zadanie 4 — przewidź wynik: ostrzeżenia o polach
Co zobaczysz w przeglądarce (zachowanie pola) i w konsoli (ostrzeżenia) dla każdego wariantu? `form.city` startuje jako `undefined` w wariancie C, w pozostałych jako `''`.
```
// @check-skip
// A
<input value={form.name} />

// B
<input defaultValue="Łódź" value={form.city} onChange={handleChange} />

// C — form = {} na starcie, potem użytkownik wpisuje tekst
<input name="city" value={form.city} onChange={handleChange} />

// D
<input type="checkbox" value={form.terms} onChange={handleChange} />

// E
<input value={form.name} readOnly />
```

#T NOTE Odpowiedź do zadania 4
- **A** — pole jest „zamrożone”: wpisywanie nic nie zmienia, bo wartość ze stanu wraca przy każdym renderze. Konsola: ostrzeżenie, że podano `value` bez `onChange` („You provided a `value` prop to a form field without an `onChange` handler”).
- **B** — ostrzeżenie, że pole ma jednocześnie `value` i `defaultValue`. Wygrywa `value`; `defaultValue` jest ignorowane. Wybierz jeden tryb.
- **C** — na starcie `value={undefined}`, więc pole jest **niekontrolowane**; po pierwszym znaku dostaje tekst i staje się kontrolowane. Ostrzeżenie: „A component is changing an uncontrolled input to be controlled”. Naprawa: zawsze inicjalizuj pola (`city: ''`), także dane z API (`value={form.city ?? ''}`).
- **D** — checkbox kontrolujesz przez `checked`, nie `value`. Tu `value` to tylko tekst wysyłany z formularza; checkbox jest niekontrolowany, a handler czyta `e.target.value` zamiast `checked`.
- **E** — poprawnie: pole tylko do odczytu, bez ostrzeżeń.

#T STEP_BY_STEP Zadanie 5 — wiele checkboxów jako tablica
Dodaj sekcję „Tematy, które Cię interesują” z checkboxami: `hooks`, `forms`, `testing`, `performance`.

Wymagania:
1. W stanie tablica wybranych tematów `topics: []`.
2. Handler `toggleTopic(topic)` dodaje albo usuwa temat (niemutowalnie).
3. Każdy checkbox: `checked={form.topics.includes(topic)}`.
4. Maksymalnie dwa tematy: pozostałe checkboxy wyłączają się, gdy wybrano dwa (ale wybrane można odznaczyć).
5. Pod sekcją: „Wybrano 1 z 2”.

Sprawdź się: po wybraniu dwóch tematów dwa pozostałe są `disabled`, a odznaczenie jednego znów je włącza.

#T CODE_JSX Rozwiązanie 5 (JSX)
```
// TopicsField.jsx
const TOPICS = { hooks: 'Hooki', forms: 'Formularze', testing: 'Testy', performance: 'Wydajność' };
const MAX = 2;

export function TopicsField({ topics, onChange }) {
  function toggleTopic(topic) {
    onChange(topics.includes(topic) ? topics.filter((t) => t !== topic) : [...topics, topic]);
  }

  return (
    <fieldset>
      <legend>Tematy, które Cię interesują</legend>
      {Object.entries(TOPICS).map(([topic, label]) => {
        const checked = topics.includes(topic);
        return (
          <label key={topic}>
            <input
              type="checkbox"
              checked={checked}
              disabled={!checked && topics.length >= MAX}
              onChange={() => toggleTopic(topic)}
            />
            {label}
          </label>
        );
      })}
      <p>Wybrano {topics.length} z {MAX}</p>
    </fieldset>
  );
}
```

#T STEP_BY_STEP Zadanie 6 — walidacja na żywo i „dotknięte” pola
Dodaj walidację imienia (min. 2 znaki) i e-maila (zawiera `@` i kropkę po nim).

Wymagania:
1. Funkcja `validate(form)` zwraca obiekt błędów, np. `{ email: 'Podaj poprawny e-mail' }` — błędy są **wyliczane** z formularza, nie przechowywane w stanie.
2. Stan `touched` — obiekt pól, które użytkownik opuścił (`onBlur`).
3. Błąd pola pokazuj, gdy pole jest dotknięte **albo** użytkownik próbował wysłać formularz (stan `submitted`).
4. Pole z błędem ma `aria-invalid` i `aria-describedby` wskazujące komunikat.
5. Przy wysłaniu z błędami — fokus nie jest wymagany, ale formularz nie może się wysłać.

Sprawdź się: przy pierwszym wejściu na stronę nie widać żadnego czerwonego komunikatu; pojawia się dopiero po opuszczeniu pola lub kliknięciu „Wyślij”.

#T CODE_JSX Rozwiązanie 6 (JSX)
```
// ValidatedForm.jsx
import { useState } from 'react';

function validate(form) {
  const errors = {};
  if (form.name.trim().length < 2) errors.name = 'Imię musi mieć co najmniej 2 znaki';
  if (!/^[^@\s]+@[^@\s]+\.[^@\s]+$/.test(form.email)) errors.email = 'Podaj poprawny e-mail';
  return errors;
}

export function ValidatedForm({ onValidSubmit }) {
  const [form, setForm] = useState({ name: '', email: '' });
  const [touched, setTouched] = useState({});
  const [submitted, setSubmitted] = useState(false);

  const errors = validate(form);
  const showError = (field) => (touched[field] || submitted) && errors[field];

  const handleChange = (e) => setForm((f) => ({ ...f, [e.target.name]: e.target.value }));
  const handleBlur = (e) => setTouched((t) => ({ ...t, [e.target.name]: true }));

  function handleSubmit(e) {
    e.preventDefault();
    setSubmitted(true);
    if (Object.keys(errors).length === 0) onValidSubmit(form);
  }

  return (
    <form onSubmit={handleSubmit} noValidate>
      {['name', 'email'].map((field) => (
        <div key={field}>
          <label htmlFor={field}>{field === 'name' ? 'Imię' : 'E-mail'}</label>
          <input
            id={field}
            name={field}
            value={form[field]}
            onChange={handleChange}
            onBlur={handleBlur}
            aria-invalid={Boolean(showError(field))}
            aria-describedby={showError(field) ? `${field}-error` : undefined}
          />
          {showError(field) && <p id={`${field}-error`} className="error">{errors[field]}</p>}
        </div>
      ))}
      <button type="submit">Wyślij</button>
    </form>
  );
}
```

#T CODE_TSX Rozwiązanie 6 (TSX)
```
// ValidatedForm.tsx
import { useState, type ChangeEvent, type FocusEvent, type FormEvent } from 'react';

type Form = { name: string; email: string };
type Field = keyof Form;
type Errors = Partial<Record<Field, string>>;

const LABELS: Record<Field, string> = { name: 'Imię', email: 'E-mail' };

function validate(form: Form): Errors {
  const errors: Errors = {};
  if (form.name.trim().length < 2) errors.name = 'Imię musi mieć co najmniej 2 znaki';
  if (!/^[^@\s]+@[^@\s]+\.[^@\s]+$/.test(form.email)) errors.email = 'Podaj poprawny e-mail';
  return errors;
}

export function ValidatedForm({ onValidSubmit }: { onValidSubmit: (form: Form) => void }) {
  const [form, setForm] = useState<Form>({ name: '', email: '' });
  const [touched, setTouched] = useState<Partial<Record<Field, boolean>>>({});
  const [submitted, setSubmitted] = useState(false);

  const errors = validate(form);
  const showError = (field: Field) => ((touched[field] || submitted) ? errors[field] : undefined);

  const handleChange = (e: ChangeEvent<HTMLInputElement>) => setForm((f) => ({ ...f, [e.target.name]: e.target.value }));
  const handleBlur = (e: FocusEvent<HTMLInputElement>) => setTouched((t) => ({ ...t, [e.target.name]: true }));

  function handleSubmit(e: FormEvent<HTMLFormElement>) {
    e.preventDefault();
    setSubmitted(true);
    if (Object.keys(errors).length === 0) onValidSubmit(form);
  }

  return (
    <form onSubmit={handleSubmit} noValidate>
      {(Object.keys(LABELS) as Field[]).map((field) => (
        <div key={field}>
          <label htmlFor={field}>{LABELS[field]}</label>
          <input
            id={field}
            name={field}
            value={form[field]}
            onChange={handleChange}
            onBlur={handleBlur}
            aria-invalid={Boolean(showError(field))}
            aria-describedby={showError(field) ? `${field}-error` : undefined}
          />
          {showError(field) && <p id={`${field}-error`} className="error">{showError(field)}</p>}
        </div>
      ))}
      <button type="submit">Wyślij</button>
    </form>
  );
}
```

#T STEP_BY_STEP Zadanie 7 — pola zależne: kraj i region

#T CODE_JSX Rozwiązanie 7 (JSX)

```
// RegionFields.jsx
import { useState } from 'react';

const REGIONS = {
  pl: ['Mazowieckie', 'Łódzkie', 'Małopolskie'],
  de: ['Bawaria', 'Berlin', 'Hesja'],
};

export function RegionFields() {
  const [address, setAddress] = useState({ country: 'pl', region: REGIONS.pl[0] });

  function handleCountry(e) {
    const country = e.target.value;
    setAddress({ country, region: REGIONS[country][0] });
  }

  return (
    <fieldset>
      <legend>Adres</legend>
      <label>
        Kraj
        <select value={address.country} onChange={handleCountry}>
          <option value="pl">Polska</option>
          <option value="de">Niemcy</option>
        </select>
      </label>
      <label>
        Region
        <select value={address.region} onChange={(e) => setAddress((a) => ({ ...a, region: e.target.value }))}>
          {REGIONS[address.country].map((r) => <option key={r} value={r}>{r}</option>)}
        </select>
      </label>
    </fieldset>
  );
}
```

```
// SaveForm.jsx
import { useState } from 'react';

function fakeSave(data) {
  return new Promise((resolve, reject) => {
    setTimeout(() => (data.email.includes('fail') ? reject(new Error('Serwer odrzucił zapis')) : resolve()), 800);
  });
}

const EMPTY = { name: '', email: '' };

export function SaveForm() {
  const [form, setForm] = useState(EMPTY);
  const [status, setStatus] = useState('idle');
  const [error, setError] = useState('');

  const handleChange = (e) => setForm((f) => ({ ...f, [e.target.name]: e.target.value }));

  async function handleSubmit(e) {
    e.preventDefault();
    setStatus('saving');
    try {
      await fakeSave(form);
      setStatus('saved');
      setForm(EMPTY);
    } catch (err) {
      setError(err.message);
      setStatus('error');
    }
  }

  return (
    <form onSubmit={handleSubmit}>
      <fieldset disabled={status === 'saving'}>
        <label>Imię <input name="name" value={form.name} onChange={handleChange} /></label>
        <label>E-mail <input name="email" value={form.email} onChange={handleChange} /></label>

      </fieldset>
      {status === 'saved' && <p role="status">Zapisano!</p>}
      {status === 'error' && <p role="alert">{error}</p>}
    </form>
  );
}
```

```
// WorkshopSignup.jsx
import { useState } from 'react';
import { TopicsField } from './TopicsField';

const INITIAL = { name: '', email: '', level: 'beginner', format: 'online', seats: '1', topics: [], terms: false };

function validate(f) {
  const errors = {};
  const seats = Number(f.seats);
  if (f.name.trim().length < 2) errors.name = 'Imię musi mieć co najmniej 2 znaki';
  if (!/^[^@\s]+@[^@\s]+\.[^@\s]+$/.test(f.email)) errors.email = 'Podaj poprawny e-mail';
  if (!Number.isInteger(seats) || seats < 1 || seats > 5) errors.seats = 'Podaj liczbę od 1 do 5';
  if (f.topics.length === 0) errors.topics = 'Wybierz co najmniej jeden temat';
  if (!f.terms) errors.terms = 'Zaakceptuj regulamin';
  return errors;
}

export function WorkshopSignup({ onSubmit }) {
  const [form, setForm] = useState(INITIAL);
  const [submitted, setSubmitted] = useState(false);
  const errors = validate(form);
  const hasErrors = Object.keys(errors).length > 0;

  function handleChange(e) {
    const { name, value, type, checked } = e.target;
    setForm((f) => ({ ...f, [name]: type === 'checkbox' ? checked : value }));
  }

  const err = (field) => submitted && errors[field]
    ? <p id={`${field}-error`} className="error">{errors[field]}</p>
    : null;
  const describe = (field) => (submitted && errors[field] ? `${field}-error` : undefined);

  function handleSubmit(e) {
    e.preventDefault();
    setSubmitted(true);
    if (!hasErrors) onSubmit({ ...form, seats: Number(form.seats) });
  }

  return (
    <form onSubmit={handleSubmit} noValidate>
      <label>Imię <input name="name" value={form.name} onChange={handleChange} aria-describedby={describe('name')} /></label>
      {err('name')}
      <label>E-mail <input name="email" value={form.email} onChange={handleChange} aria-describedby={describe('email')} /></label>
      {err('email')}
      <label>Miejsca <input name="seats" type="number" value={form.seats} onChange={handleChange} aria-describedby={describe('seats')} /></label>
      {err('seats')}
      <TopicsField topics={form.topics} onChange={(topics) => setForm((f) => ({ ...f, topics }))} />
      {err('topics')}
      <label>
        <input type="checkbox" name="terms" checked={form.terms} onChange={handleChange} aria-describedby={describe('terms')} /> Akceptuję regulamin
      </label>
      {err('terms')}
      {!errors.seats && <p>{form.seats} × 120 zł = {Number(form.seats) * 120} zł, format: {form.format}</p>}
      <button type="submit">Zapisz się</button>
    </form>
  );
}
```

#T NOTE Co dalej z tym formularzem

#T SUMMARY Podsumowanie treningu
Przećwiczyłeś obsługę każdego typu pola jako komponentu kontrolowanego: tekst, e-mail, liczba (z tekstem w stanie), checkbox (`checked`), radio, select, textarea, grupa checkboxów jako tablica, dynamiczna lista pól z kluczami, pola zależne aktualizowane w jednym handlerze i formatowanie w `onChange`.
