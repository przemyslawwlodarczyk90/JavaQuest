+ Logical Volume Manager
- Linux Virtual Memory
- Large Volume Mount
- Logical Virtual Machine

#Q
Q: Czym jest PV w LVM?
+ Woluminem fizycznym — dyskiem lub partycją przygotowaną pvcreate
- Woluminem logicznym
- Grupą woluminów
- Partycją wymiany
E: Physical volume.
#Q
Q: Czym jest VG w LVM?
+ Grupą woluminów — pulą miejsca złożoną z jednego lub wielu PV
- Woluminem fizycznym
- Systemem plików
- Partycją
E: Volume group.
#Q
Q: Czym jest LV w LVM?
+ Woluminem logicznym — „wirtualną partycją” wydzieloną z VG
- Woluminem fizycznym
- Grupą
- Dyskiem
E: Na nim system plików.
#Q
Q: Jaka jest kolejność warstw LVM?
+ Dyski/partycje → PV → VG → LV → system plików
- LV → VG → PV
- VG → PV → LV
- Partycja → LV → PV
E: Od dołu.
#Q
Q: Czym jest ekstent w LVM?
+ Jednostką przydziału miejsca (domyślnie 4 MiB)
- Partycją
- Plikiem
- Blokiem systemu plików
E: PE/LE.
#Q
Q: Jaki jest domyślny rozmiar ekstentu?
+ 4 MiB
- 1 MiB
- 512 B
- 64 MiB
E: vgdisplay PE Size.
#Q

+ Rozmiar jest zaokrąglany w górę do pełnych ekstentów (4 MiB)

- Metadane zajmują 2 MiB
- Bo dysk ma sektory 4 KiB
