lab=$(dirname "$(readlink -f "$0")")
pomoc() { echo "Uzycie: lab-ctl.sh {start|stop|status|wersja} [18094|18095]"; }

    18094|18095) ;;
    *) echo "BLAD: nieznana instancja '$port'" >&2; pomoc >&2; exit 2 ;;

        pomoc ;;
    *)
        echo "BLAD: nieznane polecenie '$1'" >&2; pomoc >&2; exit 2 ;;
esac

Q: Jaka jest składnia instrukcji case w bash?

- select $wartosc in ... done
E: Każdą gałąź kończy ;;, a całość esac.
#Q
Q: Jakie wzorce stosuje case?
+ Wzorce jak w nazwach plików: *, ?, [abc], [0-9]
- Wyrażenia regularne
- Tylko dokładne napisy
- Tylko liczby
E: Do wyrażeń regularnych służy [[ =~ ]].

- Powtórzyć gałąź
- Użyć &&

- Żadna
