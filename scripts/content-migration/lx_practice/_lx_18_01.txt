#Q
Q: Czym jest APT?
+ Menedżerem pakietów rodziny Debiana, który pobiera pakiety z repozytoriów i rozwiązuje zależności
- Formatem archiwum, w którym rozpowszechnia się programy dla Debiana
- Graficznym sklepem z aplikacjami dostępnym tylko w Ubuntu Desktop
- Narzędziem do kompilowania programów ze źródeł
E: APT (Advanced Package Tool) to warstwa nad dpkg: zna repozytoria, pobiera i instaluje pakiety .deb.
#Q
Q: Co oznacza skrót APT?
+ Advanced Package Tool
- Automatic Program Transfer
- Application Packaging Toolkit
- Advanced Patch Tracker
E: Advanced Package Tool — rozwijany od 1998 roku w projekcie Debian.
#Q
Q: Jaki format pakietów obsługuje APT?
+ .deb
- .rpm
- .apk
- .pkg.tar.zst
E: .rpm to rodzina Red Hata, .apk — Alpine, .pkg.tar.zst — Arch (rozdział 19).
#Q
Q: Które dystrybucje używają APT jako menedżera pakietów?
+ Debian, Ubuntu, Linux Mint, Pop!_OS, Raspberry Pi OS
- Fedora, Rocky Linux, AlmaLinux
- Arch Linux, Manjaro
- Alpine Linux, Void Linux
E: To rodzina Debiana; Fedora używa dnf, Arch — pacman, Alpine — apk.
#Q
Q: Co zawiera pakiet .deb?
+ Pliki programu, metadane (nazwa, wersja, zależności) i skrypty instalacyjne
- Wyłącznie skompilowany plik binarny programu
- Kod źródłowy, który instalator kompiluje na miejscu
- Tylko listę adresów, z których trzeba pobrać pliki
E: W środku są też skrypty preinst, postinst, prerm i postrm.
#Q
Q: Które skrypty mogą być częścią pakietu .deb?
+ preinst, postinst, prerm, postrm
- start, stop, restart, reload
- install.sh, uninstall.sh
- configure, make, make install
E: Uruchamia je dpkg przed i po instalacji oraz usunięciu pakietu.
#Q
Q: Czym jest repozytorium pakietów?
+ Serwerem z wieloma pakietami i podpisanym indeksem ich listy
- Katalogiem /usr/bin na lokalnym dysku
- Kopią zapasową zainstalowanych programów
- Plikiem konfiguracyjnym w /etc/apt
E: Szczegóły repozytoriów — lekcja 3.
#Q
Q: Co potrafi dpkg?
+ Instalować, usuwać i odpytywać lokalne pliki .deb — bez pobierania i rozwiązywania zależności
- Pobierać pakiety z internetu i rozwiązywać zależności
- Wyłącznie wyszukiwać pakiety w repozytoriach
- Aktualizować listę repozytoriów
E: dpkg to niskopoziomowa warstwa; zależności rozwiązuje APT.
#Q
Q: Czego dpkg NIE robi?
+ Nie pobiera pakietów z repozytoriów i nie doinstalowuje brakujących zależności
- Nie potrafi zainstalować lokalnego pliku .deb
- Nie prowadzi bazy zainstalowanych pakietów
- Nie uruchamia skryptów postinst
E: Te zadania wykonuje APT, który do samej instalacji używa dpkg.
#Q
Q: Jak APT współpracuje z dpkg przy instalacji pakietu?
+ APT rozwiązuje zależności i pobiera pliki .deb, a do ich rozpakowania i konfiguracji wywołuje dpkg
- dpkg pobiera pakiety, a APT tylko je rozpakowuje
- Działają niezależnie i nie korzystają ze swoich funkcji
- APT zastępuje dpkg, który nie jest już używany
E: Warstwy: front-end → APT → dpkg → pliki w systemie.
#Q
Q: Gdzie dpkg przechowuje bazę stanu zainstalowanych pakietów?
+ /var/lib/dpkg/status
- /etc/apt/sources.list
- /var/cache/apt/archives
- /usr/share/dpkg/packages
E: Plik tekstowy z rekordem dla każdego znanego pakietu.
#Q
Q: Czym różni się apt od apt-get?
+ apt to wygodne polecenie dla ludzi, a apt-get ma stabilny format wyjścia przeznaczony do skryptów
- apt-get jest nowszy i zastąpił apt
- apt działa tylko w Ubuntu, a apt-get tylko w Debianie
- apt nie potrafi instalować pakietów
E: apt łączy najczęstsze funkcje apt-get i apt-cache, dodając pasek postępu i kolory.
#Q
Q: Które polecenia łączy w sobie apt?
+ Najczęściej używane funkcje apt-get i apt-cache
- dpkg i tar
- apt-get i make
- aptitude i synaptic
E: Np. apt search i apt show to dawne apt-cache search/show.
#Q
Q: Którego polecenia użyjesz w skrypcie albo Dockerfile?
+ apt-get (i apt-cache) z opcją -y
- apt z opcją --interactive
- aptitude
- synaptic
E: apt nie ma stabilnego interfejsu wiersza poleceń.
#Q
Q: Jakie ostrzeżenie wypisze apt, gdy jego wyjście trafi do potoku?
+ WARNING: apt does not have a stable CLI interface. Use with caution in scripts.
- WARNING: output is not a terminal, colors disabled.
- E: apt cannot write to pipe
- WARNING: use apt-get instead of apt
E: Ostrzeżenie trafia na stderr.
#Q
Q: Na który strumień apt wypisuje ostrzeżenie o niestabilnym interfejsie?
+ stderr
- stdout
- do pliku /var/log/apt/term.log
- do dziennika systemd
E: Dlatego apt list ... | wc -l liczy linie bez ostrzeżenia, a 2>&1 je pokazuje.
#Q
Q: Do czego służy zmienna DEBIAN_FRONTEND=noninteractive?
+ Żeby instalacja nie zatrzymywała się na pytaniach konfiguracyjnych pakietów
- Żeby wyłączyć pobieranie z internetu
- Żeby APT pracował bez uprawnień roota
- Żeby pominąć sprawdzanie podpisów
E: Np. tzdata pyta o strefę czasową; w trybie noninteractive przyjmuje wartości domyślne.
#Q
Q: Co robi opcja -y w apt-get install -y?
+ Automatycznie odpowiada „tak” na pytanie o potwierdzenie
- Wyświetla dodatkowe szczegóły instalacji
- Instaluje pakiet bez zależności
- Pobiera pakiet, ale go nie instaluje
E: Bez -y skrypt zatrzyma się na „Do you want to continue? [Y/n]”.
#Q
Q: Która linia Dockerfile jest wzorcowa dla obrazu na bazie Ubuntu?
+ RUN apt-get update && apt-get install -y --no-install-recommends pakiet && rm -rf /var/lib/apt/lists/*
- RUN apt install pakiet
- RUN apt-get install pakiet && apt-get update
- RUN sudo apt upgrade -y
E: update i install w jednej warstwie, bez zalecanych pakietów, ze sprzątaniem indeksów.
#Q
Q: Po co w Dockerfile usuwa się /var/lib/apt/lists/* po instalacji?
+ Żeby indeksy repozytoriów nie zwiększały rozmiaru warstwy obrazu
- Żeby odinstalować zależności
- Bo bez tego kontener się nie uruchomi
- Żeby wyłączyć aktualizacje bezpieczeństwa
E: Indeksy zajmują dziesiątki, a nawet setki MB i nie są potrzebne w działającym kontenerze.
#Q
Q: Co robi opcja --no-install-recommends?
+ Instaluje tylko zależności wymagane (Depends), bez pakietów zalecanych (Recommends)
- Instaluje pakiet bez żadnych zależności
- Nie wyświetla zaleceń w wyniku polecenia
- Instaluje wyłącznie pakiety zalecane
E: Zależności i ich rodzaje — lekcja 6.
#Q
Q: Gdzie leży konfiguracja APT i lista repozytoriów?
+ /etc/apt/
- /var/lib/apt/
- /usr/lib/apt/
- /var/log/apt/

- Kopie zapasowe plików konfiguracyjnych
- Dziennik instalacji
