Q: Dlaczego w Dockerfile używa się --no-install-recommends?
+ Żeby obraz był mniejszy i nie zawierał zbędnych pakietów
- Bo bez tego instalacja się nie uda
- Żeby przyspieszyć start kontenera
- Bo Docker nie obsługuje Recommends
E: Np. fonty i biblioteki graficzne dla JDK.
#Q
Q: Jak globalnie wyłączyć instalowanie pakietów zalecanych?
+ Plikiem w /etc/apt/apt.conf.d/ z linią APT::Install-Recommends "false";
- Usuwając /etc/apt/sources.list
- Opcją w /etc/environment
- Plikiem ~/.aptrc
E: Np. /etc/apt/apt.conf.d/99norecommends.
#Q
Q: Na co uważać po globalnym wyłączeniu Recommends?
+ Brakujące „zalecane” funkcje (np. ca-certificates dla curl) nie zainstalują się same
- System przestanie się aktualizować
- Nie da się instalować pakietów
- Pakiety Depends też nie będą instalowane
E: Trzeba je dopisać ręcznie.
#Q
Q: Jak sprawdzić bieżącą wartość APT::Install-Recommends?
+ apt-config dump | grep Install-Recommends
- cat /etc/apt/sources.list
- apt show Install-Recommends
- dpkg --get-selections
E: Domyślnie "1" (prawda).
#Q
Q: Jak wyświetlić pakiety zalecane przez git?
+ apt-cache depends git | grep Recommends
- apt list git --recommends
- dpkg -L git
- apt-file list git
E: Także apt show git (pole Recommends).
#Q
Q: Do czego służy apt install --reinstall pakiet?
+ Do ponownej instalacji tej samej wersji, np. po przypadkowym usunięciu pliku programu
- Do aktualizacji pakietu
- Do usunięcia konfiguracji
- Do instalacji starszej wersji
E: Przywraca pliki pakietu.
#Q
Q: Jak wykryć, że brakuje pliku należącego do pakietu?
+ dpkg -V pakiet (wypisze np. missing /usr/bin/tree)
- apt list --missing
- ls /var/lib/dpkg
- apt-file update
E: dpkg --verify porównuje pliki z bazą.
#Q
Q: Co oznacza pusty wynik dpkg -V pakiet?
+ Pliki pakietu zgadzają się z bazą dpkg
- Pakiet nie jest zainstalowany
- Błąd polecenia
- Pakiet nie ma plików
E: Wypisuje tylko rozbieżności.
#Q
Q: Jaka jest kolejność kroków od potrzeby do zainstalowanego programu?
+ update → szukanie → apt show → symulacja -s → instalacja → sprawdzenie działania
- instalacja → szukanie → update
- symulacja → update → usunięcie
- apt show → instalacja → update
E: Procedura z lekcji.

E: Wynik: postgresql-client-16 i postgresql-client-common.

- Jeden z nich jest przestarzały
- Oba zawierają identyczny plik

#Q
Q: Analogia z lekcji: apt search java to...
+ Wpisanie „java” w wyszukiwarkę sklepu — setki wyników od kawy po książki
- Wyszukiwanie po numerze części
- Filtr „nazwa zaczyna się od”
- Zakup produktu
E: Wynik obejmuje nazwy i opisy.
#Q
Q: W analogii sklepu apt-file to...
+ Wyszukiwanie po numerze części — w którym zestawie jest dana śrubka
- Wyszukiwarka pełnotekstowa
- Koszyk
- Produkty polecane
E: Plik → pakiet.
#Q
Q: W analogii sklepu pakiety Recommends to...

- Części niezbędne do działania

- Paragon
E: Depends to części niezbędne.

#Q

- nginx zostanie zainstalowany ponownie
E: purge usuwa też konfigurację; pakiety bez plików konfiguracyjnych (np. htop) znikają z bazy całkowicie.
