+ Sprawdzić, czy restart jest potrzebny (reboot-required, needrestart)
- Wykonać reboot -f
- Wyłączyć SSH
- Zmienić jądro
E: Potem właściwa maszyna, użytkownicy, okno serwisowe.
#Q
Q: Jakie parametry pokazuje NEEDRESTART-SVC?
+ Usługi wymagające restartu z powodu zaktualizowanych bibliotek
- Usługi wyłączone
- Usługi w stanie failed
- Wszystkie usługi
E: Np. nginx, postgresql.
#Q
Q: Jak zrestartować usługi wskazane przez needrestart bez restartu systemu?
+ sudo needrestart -r a (automatycznie) lub systemctl restart wskazanych usług
- sudo reboot -f
- sudo daemon-reexec
- sudo update-initramfs
E: Jądro i tak wymaga restartu systemu.
#Q
Q: Jak root może wyłączyć system mimo aktywnej blokady mode=block?
+ systemctl poweroff -i (--ignore-inhibitors)
- shutdown -c
- systemd-inhibit --stop
- Nie da się
E: Świadome pominięcie blokady.
