+ docker compose logs, RestartCount i stan zdrowia usługi
- Tylko wersję Dockera
- Tylko rozmiar obrazu
- Nic
E: Logi zwykle wskazują przyczynę.
#Q
Q: Jaki jest skutek montowania docker.sock do kontenera CI?
+ Kontener uzyskuje pełną kontrolę nad demonem gospodarza — duże ryzyko
- Przyspiesza build
- Nic
- Wyłącza sieć
E: Bezpieczniej: rootless, Kaniko, Buildah.
#Q
Q: Co jest najlepszym pierwszym poleceniem, gdy ktoś mówi „kontener nie działa”?
+ docker ps -a (status i kod wyjścia)
- docker build
- docker system prune
- docker restart
E: Od statusu zależy dalsza diagnoza.
#Q
Q: Jak sprawdzić, czy proces w kontenerze naprawdę nasłuchuje na porcie 8080?
+ nsenter -t PID -n ss -tnl | grep 8080 (lub narzędzie w obrazie)
- docker port
- docker ps
- curl z gospodarza bez opublikowanego portu
E: docker port pokazuje tylko mapowanie, nie faktyczny nasłuch.
