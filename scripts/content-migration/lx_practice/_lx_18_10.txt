#Q
Q: Co robi sudo apt-mark hold pakiet?
+ Wstrzymuje pakiet — upgrade go pominie, a zmiana wersji wymaga jawnej zgody
- Usuwa pakiet
- Instaluje pakiet
- Oznacza pakiet jako ręczny
E: unhold zdejmuje blokadę.
#Q
Q: Jak wyświetlić wstrzymane pakiety?
+ apt-mark showhold
- apt list --held
- dpkg -l held
- apt hold --list
E: Także dpkg --get-selections | grep hold.
#Q
Q: Jak zdjąć wstrzymanie pakietu?
+ sudo apt-mark unhold pakiet
- sudo apt-mark release pakiet
- sudo apt unhold pakiet
- sudo dpkg --unhold pakiet
E: Komunikat: Canceled hold on pakiet.
#Q
Q: Jak upgrade raportuje wstrzymany pakiet z dostępną aktualizacją?
+ W sekcji „The following packages have been kept back”
- Jako błąd
- Nie wspomina o nim
- Jako DOWNGRADED
E: Łatwo przeoczyć jedną linię.
#Q
Q: Czy apt-mark hold i dpkg --set-selections hold to ten sam mechanizm?
+ Tak — oba ustawiają stan wybrania „hold” w bazie dpkg
- Nie, działają niezależnie
- dpkg nie obsługuje hold
- Tylko w Debianie
E: dpkg --get-selections pokazuje to samo.
#Q
Q: Jakie ryzyko niesie zapomniane hold na bibliotece bezpieczeństwa?
+ Pakiet nie dostaje łatek, a aktualizacje raportują sukces
- System przestaje się uruchamiać
- APT się blokuje
- Nic
E: Luka zostaje miesiącami.
#Q
Q: Jak instalować konkretną wersję pakietu?
+ sudo apt install pakiet=wersja
- sudo apt install pakiet -v wersja
- sudo apt install pakiet@wersja
- sudo apt version pakiet wersja
E: Wersja musi być w repozytorium.

- Dotyczy pakietów lokalnych

- Dotyczy wersji jądra
- Dotyczy daty wydania

- origin dotyczy wersji
- release dotyczy hosta
E: Np. origin packages.adoptium.net vs release o=Adoptium.

- Żeby wyłączyć podpisy
- Żeby repozytorium było domyślne
E: Wzorzec z lekcji dla Adoptium.

- Tylko z --force
- Tylko w Debianie

- Dowolne

- Lista dostawców
- Faktura
E: Blokuje też poprawki.
#Q
Q: W analogii lekcji pinning to...

- Kartka NIE RUSZAĆ
- Inwentarz
- Zwrot towaru
E: Priorytet = miejsce na liście.
#Q
Q: Co spowoduje przypięcie openssl do starej wersji z priorytetem 1001?
+ APT zaproponuje obniżenie wersji przy najbliższym upgrade
- Nic
- Usunięcie openssl
- Wstrzymanie openssl
E: Dlatego >1000 używa się bardzo ostrożnie.
#Q
Q: Dlaczego przypięcie postgresql-client-16 na 1001 z version 16.* nie powoduje obniżenia wersji?

- Bo 1001 działa tylko na nowsze wersje
- Bo APT ignoruje przypięcia
- Bo pakiet jest wstrzymany
E: 16.10 > 16.2.

Q: Który zestaw najlepiej streszcza lekcję?

- Pliki preferencji mogą mieć dowolną nazwę

- Priority: optional oznacza priorytet 100

Q: Co się stanie, gdy dwa bloki preferencji pasują do tego samego pakietu?

#Q
Q: Jak w preferencjach wskazać wiele pakietów jednym blokiem?

- Użyć Package: all
E: Gwiazdka * oznacza wszystkie pakiety.
