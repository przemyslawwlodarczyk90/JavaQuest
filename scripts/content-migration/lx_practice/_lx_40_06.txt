#Q
Q: Co robi alias?
+ Podstawia zapamiętany tekst w miejscu pierwszego słowa polecenia
- Uruchamia osobny skrypt z argumentami w dowolnym miejscu
- Zmienia uprawnienia programu
- Tworzy dowiązanie do programu
E: Argumenty podane przy użyciu aliasu trafiają na koniec rozwiniętego tekstu.
#Q
Q: Gdzie trafiają argumenty podane po aliasie `pokaz /etc`, gdy alias pokaz='ls -1'?
+ Na koniec: ls -1 /etc
- Na początek
- Do zmiennej $1
- Są ignorowane
E: Alias nie ma argumentów w środku definicji.
#Q
Q: Kiedy zamiast aliasu użyć funkcji?
+ Gdy potrzebne są argumenty w środku, wartości domyślne, warunki lub kilka kroków
- Zawsze, gdy polecenie ma opcje
- Gdy polecenie jest krótkie
- Nigdy
E: Funkcja to mini-skrypt działający w bieżącej powłoce.
#Q
Q: Jak zdefiniować funkcję w bash?
+ nazwa() { polecenia; } lub function nazwa { polecenia; }
- def nazwa: polecenia
- nazwa = { polecenia }
- alias nazwa() polecenia
E: Średnik przed zamykającym nawiasem klamrowym jest wymagany w zapisie jednoliniowym.
#Q
Q: Gdzie zapisać aliasy i funkcje, by działały w każdej nowej sesji?
+ W ~/.bashrc lub ~/.bash_aliases
- W /etc/environment
- W ~/.profile tylko
- W historii
E: Wzorcowy ~/.bashrc Ubuntu wczytuje ~/.bash_aliases.
#Q
Q: Jak wczytać zmiany w ~/.bash_aliases bez otwierania nowego terminala?
+ source ~/.bash_aliases
- bash ~/.bash_aliases
- export ~/.bash_aliases
- chmod +x ~/.bash_aliases
