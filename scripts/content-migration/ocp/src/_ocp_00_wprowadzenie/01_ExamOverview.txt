#T INTRO Ostatni etap kursu Java: certyfikat OCP Java SE 21 Developer
Ten tor zamyka naukę Javy. Znasz już język od zmiennych po współbieżność i moduły. Teraz trzeba sprawdzić tę wiedzę tak, jak robi to Oracle na egzaminie **Oracle Certified Professional: Java SE 21 Developer** (kod egzaminu **1Z0-830**).

Tor składa się z trzech części:

1. **Ta lekcja** — czym jest egzamin, co obejmuje i jak rozwiązywać jego pytania.
2. **Rozdziały 01–12** — bank około 2000 pytań w formacie egzaminu, podzielony na obszary z oficjalnego programu. Każda lekcja zaczyna się krótką ściągą reguł, a quiz losuje za każdym razem 20 pytań z puli lekcji. Najpierw trafiają się pytania, których jeszcze nie widziałeś, i te, na które odpowiedziałeś źle.
3. **Test wiedzy Java** — 500 pytań otwartych z całego ekosystemu Javy: JVM, SQL i transakcje, Spring, testowanie i wydajność. Działają jak zadania: czytasz pytanie, formułujesz odpowiedź, w razie potrzeby odsłaniasz podpowiedź, a na końcu porównujesz się z odpowiedzią wzorcową. Kolejność pytań jest losowana przy każdym wejściu.

#T DEFINITION Czym jest certyfikat OCP
OCP (Oracle Certified Professional) to certyfikat Oracle potwierdzający, że programista zna **reguły języka Java i standardowe API** na poziomie pozwalającym przewidzieć zachowanie kodu bez uruchamiania go.

Dawniej ścieżka miała dwa stopnie: OCA (Associate) i OCP (Professional). Od Javy 11 jest jeden egzamin OCP dla danej wersji LTS:
- Java SE 11 — 1Z0-819,
- Java SE 17 — 1Z0-829 (Oracle zapowiedziało jego wycofanie),
- **Java SE 21 — 1Z0-830** — wersja, pod którą przygotowany jest ten tor.

Egzamin nie sprawdza frameworków (Spring, Hibernate) ani narzędzi (Maven, IDE). Sprawdza wyłącznie Javę SE: język, bibliotekę standardową i maszynę wirtualną w zakresie widocznym dla programisty.

#T NOTE Format egzaminu 1Z0-830
- około **50 pytań** wielokrotnego wyboru,
- **120 minut**, czyli średnio 2 minuty i 24 sekundy na pytanie,
- próg zaliczenia około **68%**,
- wiele pytań zawiera fragment kodu i pyta o wynik, błąd kompilacji albo wyjątek,
- część pytań ma **kilka poprawnych odpowiedzi** („Choose two”, „Choose three”) — trzeba zaznaczyć dokładnie tyle, ile podano,
- egzamin jest po angielsku i zdaje się go w centrum Pearson VUE albo zdalnie z kamerą.

Liczba pytań, czas i próg mogą się zmieniać — przed zapisem sprawdź aktualne dane na stronie Oracle University. W tym kursie każde pytanie ma jedną poprawną odpowiedź spośród czterech, a pytania z kilkoma poprawnymi odpowiedziami zostały przerobione na wybór najlepszej kombinacji.

#T DEFINITION Oficjalne obszary egzaminu i rozdziały tego toru
Program 1Z0-830 jest podzielony na dziesięć obszarów. Rozdziały tego toru odpowiadają im tak:

- Handling Date, Time, Text, Numeric and Boolean Values → rozdział 01 (typy, operatory, String) i rozdział 10 (data i czas),
- Controlling Program Flow → rozdział 02,
- Using Object-Oriented Concepts in Java → rozdziały 03 i 04 (klasy, dziedziczenie, rekordy, enumy, klasy sealed, pattern matching),
- Handling Exceptions → rozdział 05,
- Working with Arrays and Collections → rozdział 06 (razem z typami generycznymi),
- Working with Streams and Lambda expressions → rozdział 07,
- Packaging and Deploying Java Code → rozdział 11 (moduły JPMS),
- Managing Concurrent Code Execution → rozdział 08 (w tym wątki wirtualne),
- Using Java I/O API → rozdział 09,
- Implementing Localization → rozdział 10.

Rozdział 12 zbiera zagadnienia, które pojawiają się na pograniczu obszarów: adnotacje, logowanie, klasy `Math`, `Objects`, tablice i pytania przekrojowe.

#T NOTE Skąd pochodzą pytania w tym torze
Prawdziwe pytania z egzaminu Oracle są poufne: każdy zdający akceptuje umowę o zachowaniu poufności, a krążące w internecie zbiory typu „dump” to wycieki naruszające tę umowę i prawa autorskie. Nauka z nich jest ryzykowna także dlatego, że często zawierają błędne odpowiedzi.

Pytania w tym torze są **autorskie, ale wzorowane na formacie i poziomie egzaminu**: oparte na oficjalnym programie 1Z0-830, specyfikacji języka (JLS 21) i dokumentacji API. Każde pytanie z kodem, w którym pytamy o wynik, wyjątek albo błąd kompilacji, zostało **sprawdzone kompilatorem JDK z opcją `--release 21`** — klucz odpowiedzi nie jest zgadywany.

Do dalszej nauki warto sięgnąć po podręczniki przygotowujące do tego egzaminu (np. Boyarsky i Selikoff, „OCP Oracle Certified Professional Java SE 21 Developer Study Guide”) oraz po pytania przykładowe publikowane przez Oracle University.

#T STEP_BY_STEP Jak czytać pytanie z kodem
1. **Najpierw przeczytaj odpowiedzi.** Jeśli wśród nich jest „Błąd kompilacji” albo „Wyjątek w czasie działania”, autor pytania prawie na pewno umieścił w kodzie pułapkę.
2. **Sprawdź kompilację, zanim zaczniesz liczyć wynik.** Szukaj: brakującego `return`, niezainicjalizowanej zmiennej lokalnej, nieosiągalnego kodu, niezgodnych typów, nieobsłużonego wyjątku kontrolowanego, wywołania metody na złym typie referencji, przypisania do zmiennej `final`.
3. **Ustal typy wyrażeń.** Promocja do `int` przy `byte`/`short`/`char`, autoboxing, wybór przeciążonej metody, typ wyniku operatora warunkowego.
4. **Dopiero potem śledź wykonanie** — linia po linii, zapisując wartości zmiennych na kartce.
5. **Uważaj na wyjątki w czasie działania**: `ClassCastException`, `NullPointerException`, `ArrayIndexOutOfBoundsException`, `UnsupportedOperationException` przy niemodyfikowalnych kolekcjach, `IllegalStateException` przy ponownym użyciu strumienia.

W pytaniach z kodem w tym torze zakładamy, że **potrzebne importy są obecne**, chyba że samo pytanie dotyczy importów. Fragment kodu bez deklaracji klasy znajduje się wewnątrz metody `main`. Domyślna lokalizacja to `Locale.US` (kropka jako separator dziesiętny), a domyślna strefa czasowa to UTC — chyba że pytanie mówi inaczej.

#T PITFALL Najczęstsze pułapki egzaminacyjne
- Kod, który „wygląda” poprawnie, ale się nie kompiluje — np. `int x; System.out.println(x);` dla zmiennej lokalnej.
- Podobne nazwy API: `List.of` jest niemodyfikowalna, a `Arrays.asList` pozwala na `set`, ale nie na `add`.
- `String` jest niemutowalny: `s.concat("x");` bez przypisania niczego nie zmienia.
- Kolejność inicjalizacji: bloki statyczne, potem pola i bloki instancyjne, na końcu reszta konstruktora.
- Przesłanianie metod a ukrywanie metod statycznych i pól.
- `switch` ze strzałką nie ma przechodzenia do kolejnych przypadków, a `switch` z dwukropkiem — ma.
- Pytania typu „Które stwierdzenie jest prawdziwe?” — każde słowo ma znaczenie („zawsze”, „nigdy”, „może”).

#T USAGE Jak korzystać z tego toru
- Przejdź rozdziały 01–12 w kolejności albo zacznij od obszaru, który znasz najsłabiej.
- Przed quizem przeczytaj ściągę lekcji — jest krótka i zawiera dokładnie te reguły, o które pytają pytania.
- Rozwiązuj quiz wielokrotnie: każde podejście losuje 20 pytań, a pytania z błędną odpowiedzią wracają w kolejnych podejściach.
- Gwiazdki działają jak w całym JavaQuest: pierwsza za zaliczenie, kolejne za powtórki w odstępach czasu. Bank jest duży, więc pełne opanowanie wymaga wielu podejść — o to chodzi.
- Test wiedzy Java rozwiązuj „na głos”: spróbuj wyjaśnić odpowiedź pełnymi zdaniami, zanim odsłonisz wzorzec.

#T WHEN_TO_USE Kiedy jesteś gotowy na egzamin
Dobry sygnał gotowości to:
- co najmniej trzy gwiazdki w większości lekcji tego toru,
- stały wynik powyżej 80% przy pierwszym podejściu do nowych pytań,
- umiejętność wyjaśnienia, **dlaczego** błędne odpowiedzi są błędne — a nie tylko wskazania poprawnej.

Przed egzaminem warto rozwiązać jeszcze pełny egzamin próbny z oficjalnego materiału Oracle albo podręcznika, w limicie 120 minut.

#T SUMMARY Podsumowanie
OCP Java SE 21 Developer (1Z0-830) sprawdza precyzyjną znajomość języka i biblioteki standardowej. Ten tor łączy krótką ściągę reguł w każdej lekcji z dużym bankiem autorskich pytań sprawdzonych kompilatorem oraz z otwartym Testem wiedzy Java, który obejmuje także bazy danych, transakcje, Springa i JVM. Czytaj pytania od odpowiedzi, sprawdzaj kompilację przed liczeniem wyniku i ucz się na błędach — pytania źle rozwiązane wracają w kolejnych podejściach.
